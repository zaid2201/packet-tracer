# Access Control Lists (ACLs)

##  Overview

This section contains Cisco Packet Tracer labs focused on configuring and testing Access Control Lists (ACLs).

ACLs are used to control network traffic by permitting or denying packets based on defined rules.

##  Labs

### Standard ACL
Practice configuring Standard ACLs to filter traffic based primarily on the source IPv4 address.

### Extended ACL
Practice configuring Extended ACLs to filter traffic based on source and destination addresses, protocols, and port numbers.

## Concepts Practiced

- Standard ACLs
- Extended ACLs
- Permit and deny statements
- Wildcard masks
- Inbound and outbound ACLs
- Applying ACLs to router interfaces
- ACL verification and troubleshooting
- Network traffic filtering
